# AI 原生工作流

## 第一支柱：可执行的规范（Specs）
1. 定义意图。WHAT 和 WHY，输出 spec.md。
2. 技术规划。HOW。根据 consituion.md 进行技术选型、架构设计、模块划分和 API 定义。输出 plan.md。
3. 任务分解。拆解，输出 tasks.md。
4. 自动化实现。根据 tasks.md，AI Agent 输出代码，测试用例和文档。
   
## 第二支柱：持久化的上下文
通过CLAUDE.md、agents.md这类标准化的上下文文件，我们可以为 AI 提供关于项目的“长期记忆”。更重要的是，这种记忆是分层的、持久化的。

1. 企业级记忆：整个公司的安全红线、合规要求。
2. 项目级记忆：constitution.md 中定义的技术选型、架构原则、编码“宪法”。
3. 模块级记忆：特定模块的 API 设计、核心逻辑。
4. 个人级记忆：你个人的代码风格偏好。

## 第三支柱：可编排的行动
自定义指令（Slash Commands）、钩子（Hooks）和 MCP 服务器，为它打造一个几乎无限扩展的“工具箱”。
